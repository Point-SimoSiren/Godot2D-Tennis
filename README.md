# Pallomaila

Yksinkertainen Godot 4:n 2D-peli. Ylhäältä tuleva pallo kimpoaa seinistä ja mailasta. Kun pallo osuu kolikkoon, kolikko katoaa ja saat 10 pistettä. Peli laskee myös mailaosumat ja ohitukset. Ohituksen jälkeen uusi pallo saapuu automaattisesti. Kun kaikki kolikot on kerätty, seuraavan pallon mukana ilmestyy uusi erä kolikoita.

## Käynnistys

1. Avaa tämä kansio Godotissa projektina.
2. Käynnistä peli painamalla **F6** tai **F5**.

Komentoriviltä: `godot --path .`

## Ohjaus

- Liikuta hiirtä tai vedä kosketusnäytöllä.
- Vaihtoehtoisesti käytä **vasen/oikea**-nuolinäppäimiä tai **A/D**.

Pallon kimpoamiskulma riippuu mailan osumakohdasta. Pallo nopeutuu hieman jokaisella mailaosumalla.
